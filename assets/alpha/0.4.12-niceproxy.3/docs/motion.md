# Движение

Скорость и сглаживание независимы. Скорости: `--as-motion-fast: 0.4s`, `--as-motion-normal: 0.6s`. Сглаживания: `--as-motion-switch: cubic-bezier(.5,.4,0,1)` для кнопок/переключений состояния; `--as-motion-transition: cubic-bezier(.2,.66,0,1)` для плавной смены представления. Любая кривая работает с любой скоростью.

Hover: задержка 0.033s, длительность 0.166s. Нажатие: 0.166s без задержки; отпускание: 0.4s без задержки. Подключи `installControlMotion()` из `@alpha/core` один раз на уровне приложения для мыши и клавиатуры. Контролы по умолчанию используют Switch. Сглаживание контролов можно менять через `data-motion-easing="transition"` или `--as-control-easing`. Скорости fast/normal остаются независимыми от кривых для переходов представлений. Не используй неявный `ease` или `linear` для этих переходов. Движение пунктира Loading — отдельная циклическая анимация.

В `@alpha/core` экспортируется `transitionView(update)`. Оберни единственную сменяемую область в `.as-view`. Демо React/Qwik используют этот API при навигации. React передаёт синхронный DOM commit через `flushSync`. Qwik ждёт фактическое обновление DOM через `waitForViewCommit`, а не таймер предполагаемой длительности рендера.

View Transition по умолчанию использует Transition/normal. Для другой скорости задай на `<html>` `data-motion-speed="fast"` или CSS-переменную `--as-view-duration`; кривую независимо меняй через `--as-motion-transition`. Не назначай одно имя `alpha-view` нескольким видимым элементам одновременно. Подключение маршрутизатора своего проекта выполняется на уровне приложения, а не внутри Button.

Если API недоступен, либо пользователь включил reduced motion, обновление выполняется без снимков и анимации. Ошибки обновления не скрываются. [Документация View Transition API](https://developer.mozilla.org/en-US/docs/Web/API/Document/startViewTransition).
